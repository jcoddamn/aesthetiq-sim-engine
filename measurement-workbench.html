    Calibrated geometry calculator

    Pixels need a documented scale in the same plane. Metric 3D data must come from a verified scanner; FaceMesh depth is not millimeters. Angle uses the second point as vertex. Ratio uses four endpoints. Area is a simple 2D polygon. Circumference requires a complete planar 3D section. Volume requires a closed, consistently oriented, connected triangle mesh with verified absence of self-intersections and a fixed closure protocol. These checks do not validate the scanner.

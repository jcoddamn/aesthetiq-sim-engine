# AesthetIQ canonical facial geometry

**File:** `mediapipe_canonical_face.obj`

**Upstream:** Google MediaPipe canonical face geometry

**Original source:** https://github.com/google-ai-edge/mediapipe/blob/master/mediapipe/modules/face_geometry/data/canonical_face_model.obj

**License:** Apache License, Version 2.0

**License text:** https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE

The geometry is the unmodified upstream 468-vertex canonical reference face model. AesthetIQ's viewer parses and deforms a runtime copy of the mesh. It does not represent an individual's scanned anatomy or a validated surgical result.

Additional skull, neck, and ear primitives are authored in AesthetIQ's `faceViewer.js` and are schematic, not part of the MediaPipe asset.
